## Core competencies

### DevSecOps & automation

- Secure CI/CD pipelines and GitHub Actions workflows
- Automated infrastructure validation and deployment checks
- Developer tooling that balances speed with risk reduction

### Cloud security

- Identity and access model review
- Cloud misconfiguration detection and remediation
- Runtime security and least-privilege design

### Kubernetes security

- Cluster hardening and policy enforcement
- Runtime detection and log analysis
- Attack simulation and defense validation

### Security research & learning

- Web application vulnerability analysis
- Offensive testing walkthroughs and post-exploitation research
- Written technical documentation for security teams and engineers
